# ConsultPro - Company Website

A clean, responsive business website designed for a professional consulting firm. This project serves as the company's primary digital storefront, showcasing core services, introducing the executive team, and providing a direct line of communication for potential clients.

## Project Overview

The website features an optimized layout that seamlessly transitions between desktop and mobile viewports. It includes dedicated sections for service breakdowns, an about page outlining the company mission, and a fully functional, interactive contact form designed to streamline client inquiries.

---

## Tech Stack

The frontend is constructed using semantic HTML5 structures paired with responsive CSS3 layouts. Minimal, vanilla JavaScript handles the interactive components and form validations to ensure quick page load times without heavy external dependencies.

---

## Getting Started

To view the project locally, clone this repository to your machine using your terminal. Once downloaded, navigate into the main folder and open the index.html file in any modern web browser to run the application.

---

## Project Structure

Inside the repository, the source files are organized into a dedicated assets directory containing specific folders for CSS stylesheets, JavaScript files, and visual media. The main index file resides in the root directory alongside this documentation for easy access.
